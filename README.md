# kai-tools

Optional, independently usable packages shared between kaicreator-mm projects.

This repository is intentionally small. Packages are accepted based on real reuse value, not merely because code already exists elsewhere. In particular, xDownload v0.1 remains independent of kai-tools and keeps its existing reviewed sources.

Development and review follow the organization's current ADS standards and the Web-first approach. Source lineages, platform constraints, and unverified host results are documented per package.

See [intake #1](https://github.com/kaicreator-mm/kai-tools/issues/1).
